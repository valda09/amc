# 🖥 Arquitetura e Manutenção de Computadores - AMC

 # Sobre AMC

Arquitetura e Manutenção de Computadores (AMC) é a área da informática dedicada ao estudo dos componentes físicos dos computadores, suas funções, organização e funcionamento.

# ⚙️ Configuração do computador

Este documento apresenta os principais componentes de um computador de mesa (desktop), identificados a partir de um gabinete que estava funcionando, mas apresentava algumas peças faltando.

# 🔧 Componentes de hardware

1. Placa-mãe: IPX1800E2.

2. Processador: Intel Celeron Dual-Core J1800, com frequência de 2,41 GHz.

3. Memória RAM: 4 GB DDR3.

4. Armazenamento: SSD de 120 GB.

5. Sistema Operacional: Linux ou compatível com versões leves do Windows 10/11.

# Arquitetura do computador

O computador é composto por diferentes peças de hardware que trabalham em conjunto para permitir seu funcionamento. Cada componente possui uma função específica, desde o processamento de informações até o armazenamento de arquivos.

Apesar de estar funcionando, o gabinete apresentava algumas peças faltando, demonstrando que dependendo das peças ausentes, os componentes de um computador precisam estar presentes para que ele funcione.
